## A. Quantum linear-system algorithms and their fine print

### QCS-001 — HHL's poly(log N) runtime holds only under four conditions, and its output is a state, not a vector
- claim: HHL solves Ax = b in time polylogarithmic in N only if A is s-sparse and efficiently row-computable, |b> is efficiently preparable, the condition number kappa is small, and the user settles for the quantum state |x> (from which only expectation values <x|M|x> are sampled) rather than the classical vector x.
- numbers: quantum runtime Õ(log(N) s^2 kappa^2 / eps), eps = additive error in the output state |x>, kappa = ratio of largest to smallest singular value (singular values of A assumed in [1/kappa, 1]), s = max nonzeros per row; phase-estimation time t0 = O(kappa/eps); post-selection success probability Omega(1/kappa^2), O(kappa) amplitude-amplification repetitions (at most 4 kappa, Appendix A). Classical comparison quoted by the paper's abstract: O(N sqrt(kappa)) to find x and estimate x†Mx; Sec. III gives CG for positive-definite A at O(N s sqrt(kappa) log(1/eps)) matrix-vector products, and O(N s kappa log(1/eps)) otherwise. Aaronson's "four caveats" (S. Aaronson, "Read the fine print," Nature Physics 11(4), 291-293 (2015-04), doi:10.1038/nphys3272; author's preprint https://www.scottaaronson.com/papers/qml.pdf): loading b, applying e^(-iAt), and the kappa scaling each individually reduce HHL to no exponential advantage if they cost n^c for any constant c > 0, and reading out |x> does the same because learning any specific entry x_i needs roughly n repetitions (n = number of equations). Precision: Childs, Kothari, Somma (SIAM J. Comput. 46(6), 1920-1950 (2017), doi:10.1137/16M1087072; arXiv:1511.02306) cut the output-state error dependence to poly log(1/eps), but observable estimation still pays 1/eps — for the expectation-value version "sampling error alone rules out" poly log(1/eps) unless BQP = PP (their Sec. 1), see QCS-009.
- source: A. W. Harrow, A. Hassidim, S. Lloyd, "Quantum algorithm for linear systems of equations," Phys. Rev. Lett. 103, 150502 (2009), doi:10.1103/PhysRevLett.103.150502; arXiv:0811.3171. https://arxiv.org/abs/0811.3171
- verified: 2026-10-07 — arXiv abstract page via WebFetch; full arXiv PDF v3 via WebFetch + pdftotext: Sec. I (assumptions: s-sparse row-computable A, efficient |b> preparation, expectation-value output) and Sec. II "Run-time and error analysis" (Õ(log(N)s^2 kappa^2/eps)). Supporting read: local HHL tutorial PDF /Users/agallojr/proj/src/research-notes/bus/memory/refs/ref-20260809-0006-quantum-hhl-tutorial.pdf (Galvão et al., arXiv:2509.16640v2), Sec. "Limitations" (state preparation, QRAM, tomography readout); independently re-verified 2026-10-07 (arXiv:0811.3171v3 PDF via pdftotext: abstract O(N sqrt(kappa)) classical figure, Sec. I assumptions, Sec. II runtime Õ(log(N)s^2 kappa^2/eps) with t0 = O(kappa/eps) and success probability Omega(1/kappa^2), Sec. III CG costs, Appendix A <= 4 kappa repetitions; Crossref record for doi:10.1103/PhysRevLett.103.150502 (PRL 103(15), 150502, published 2009-10-07); local Galvão et al. tutorial PDF header arXiv:2509.16640v2 dated 2026-02-08 and Sec. V.B "Algorithm Limitations"); fold-in: Aaronson's four caveats from a cut entry whose source was read 2026-10-07 (full text of the author's preprint PDF via WebFetch + pdftotext, caveats (1)-(4) verbatim; Crossref record for doi:10.1038/nphys3272, Nature Physics 11(4), 291-293, online 2015-04-02); fold-in: Childs-Kothari-Somma poly log(1/eps) state precision and the BQP = PP sampling remark from a cut entry whose source was read 2026-10-07 (arXiv:1511.02306v2 PDF via WebFetch + pdftotext, Sec. 1 and Theorems 3, 4, 5; Crossref record for doi:10.1137/16M1087072, SIAM J. Comput. 46(6), 1920-1950, online 2017-12-21)
- strength: strong
- counter: Two of the four conditions have since been weakened at the algorithm level: kappa-dependence is now strictly linear, O(kappa log(1/eps)), matching the lower bound (Costa, An, Sanders, Su, Babbush, Berry, PRX Quantum 3, 040303 (2022), arXiv:2111.08152; abstract and Sec. I main theorem read 2026-10-07), and eps-dependence is poly log(1/eps) (Childs, Kothari, Somma, SIAM J. Comput. 46, 1920 (2017); abstract read 2026-10-07). For PDE discretizations A is generated algorithmically with no QRAM and b is known from the problem description (Montanaro and Pallister, PRA 93, 032324 (2016), Sec. I; Alkadri, Kharazi, Whaley, Mandadapu, Qu-FEM, arXiv:2510.18150, Sec. 7 — local PDF read 2026-10-07).

### QCS-002 — Matrix inversion is BQP-complete, so sublinear-in-kappa QLSAs are impossible unless BQP = PSPACE
- claim: No quantum algorithm can solve the sparse QLSP with kappa^(1-delta) scaling for any delta > 0 (or polylog(kappa)) unless BQP = PSPACE, and no algorithm can estimate <x|M|x> to additive eps in poly log(1/eps) time unless BQP contains PP; the linear-in-kappa cost of every QLSA is a lower bound, not an artifact of the method.
- numbers: reduction: an n-qubit, T-gate quantum circuit is simulated by inverting an O(1)-sparse matrix A = I - U e^(-1/T) of dimension N = O(2^n kappa) with kappa(A) = O(T) (general) or O(T^2) (positive-definite); the useful time-register outcome occurs with probability e^-2/(1 + e^-2 + e^-4) >= 1/10 per run. Formal query lower bound for the sparse QLSP: Omega(kappa log(1/eps)) oracle queries, stated in Costa et al. 2022 (Sec. I and Table I caption) — but their ref. [17] for it is "A. W. Harrow and R. Kothari, in preparation (2021)", and An, Liu, Wang, Zhao arXiv:2211.05246 ref. [36] cite the same Omega(log(1/eps)) bound as "private communication, 2022"; no published proof of the combined Omega(kappa log(1/eps)) bound is cited by either paper. Published lower-bound evidence is HHL's BQP-completeness argument above plus Orsucci and Dunjko, Quantum 5, 573 (2021), which Dalzell arXiv:2406.12086 cites for linear-in-kappa optimality.
- source: A. W. Harrow, A. Hassidim, S. Lloyd, Phys. Rev. Lett. 103, 150502 (2009), doi:10.1103/PhysRevLett.103.150502; arXiv:0811.3171, Sec. III "Optimality" (paragraphs "The complexity of matrix inversion" and "The reduction"). https://arxiv.org/abs/0811.3171
- verified: 2026-10-07 — arXiv PDF v3 via WebFetch + pdftotext, Sec. III (BQP=PSPACE and BQP ⊇ PP statements, Eq. (4)-(5) reduction, "matrix inversion is BQP-complete"); Costa et al. arXiv:2111.08152 PDF v1 Sec. I and Table I for the Omega(kappa log(1/eps)) lower-bound statement; independently re-verified 2026-10-07 (arXiv:0811.3171v3 PDF via pdftotext Sec. III: kappa^(1-delta) and polylog(kappa) → BQP=PSPACE, poly log(1/eps) → BQP ⊇ PP, A = I - U e^(-1/T) with kappa(A) = O(T), N = O(2^n kappa), probability e^-2/(1+e^-2+e^-4) >= 1/10; Costa et al. arXiv:2111.08152v1 PDF Sec. I, Table I caption, Sec. VI and reference list entry [17] "In preparation (2021)"; An et al. arXiv:2211.05246v3 reference [36]; Dalzell arXiv:2406.12086v2 Sec. 1 refs [1, 13])
- strength: strong
- counter: BQP-completeness is also the strongest pro-quantum fact in the field: there exist linear systems on which HHL is exponentially faster than any classical algorithm (unless BQP = BPP), as Aaronson concedes in "Read the fine print," Nature Physics 11, 291 (2015) (full text read 2026-10-07; he calls the instances "extremely artificial"). The kappa bound is worst-case over oracle inputs; for structured PDE operators preconditioning can remove it — Bagherimehrab, Nakaji, Wiebe, Brennen, Sanders, Aspuru-Guzik, arXiv:2306.11802 (v3, 2025-09-15, no journal reference) claim complexity "polylogarithmic in N but independent of kappa" for a large class of PDEs via a wavelet diagonal preconditioner (abstract read 2026-10-07).
- applies-to: qlsa, hhl, kappa, precision, classical-baseline
- stale-after: 2030-01-01

### QCS-003 — An optimal O(kappa log(1/eps)) QLSA exists and matches the lower bound (pro-quantum)
- claim: There is a quantum linear-system solver whose query complexity is O(kappa log(1/eps)) — strictly linear in kappa and logarithmic in 1/eps — matching the Omega(kappa log(1/eps)) lower bound as stated by the authors, so the asymptotic kappa-scaling of quantum linear solvers is settled at linear.
- numbers: O(kappa log(1/eps)) calls to a block-encoding of A (normalized so ||A|| = 1, ||A^-1|| = kappa, spectral norm) and to the |b> preparation oracle; eps = error in the normalized output state A^-1|b>. Constant factors (Thm 17, Eqs. 142-143): with T >= kappa quantum-walk steps and schedule exponent p = 3/2, error <= 5632 kappa/T + O(sqrt(kappa)/T) for positive-definite Hermitian A and <= 15307 kappa/T + O(sqrt(kappa)/T) for general A; the authors' own numerics (Sec. V, Fig. 4) suggest about 638 kappa/T for p = 3/2, roughly 9x below the proven constant. Prior best (Table I): O(kappa log(kappa/eps)) via Zeno eigenstate filtering (Tong and Lin 2019). The lower bound the paper matches is attributed to Harrow and Kothari, "in preparation (2021)" (ref. [17]); it was unpublished at the time. Tightest proven constant for an asymptotically optimal QLSS: 56 kappa + 1.05 kappa ln(1/eps) + o(kappa) expected queries to the block-encoding of A (eps = trace-distance error; Theorem 4, Eq. (133): Q <= 56.0 kappa + 1.05 kappa ln(sqrt(1 - eps^2)/eps) + 2.78 ln(kappa) + 3.17, plus 2Q queries to U_b), about 80 kappa at (kappa, eps) = (10^5, 10^-10) against 234562 kappa for this quantum-walk method, 2173 kappa for the randomization method and 1728 kappa with Poissonization (A. M. Dalzell, "A shortcut to an optimal quantum linear system solver," arXiv:2406.12086 (v2, 2026-04-08; no journal reference listed on arXiv as of 2026-10-07), Table 1); numerics on 16 x 16 random matrices with kappa <= 50 (Dalzell's reading of Costa, An, Babbush, Berry, Quantum 9, 1887 (2025)) suggest the quantum-walk method actually costs about 15 kappa + 2.1 kappa ln(1/eps).
- source: P. C. S. Costa, D. An, Y. R. Sanders, Y. Su, R. Babbush, D. W. Berry, "Optimal scaling quantum linear-systems solver via discrete adiabatic theorem," PRX Quantum 3, 040303 (published 2022-10-07), doi:10.1103/PRXQuantum.3.040303; arXiv:2111.08152. https://arxiv.org/abs/2111.08152
- verified: 2026-10-07 — arXiv abstract via WebFetch; arXiv PDF v1 via WebFetch + pdftotext: Sec. I Table I and main Theorem (QLSP with linear dependence on kappa), Sec. V Theorem 17 (explicit constants); journal reference via the PRX Quantum landing page and the Crossref API record; independently re-verified 2026-10-07 (arXiv:2111.08152v1 PDF via pdftotext: abstract, Sec. I Table I rows and caption, Sec. V Theorem 17 Eqs. (142)-(143) with T >= kappa and p = 3/2, Fig. 4 discussion "638 kappa/T ... around 9 times" smaller, Sec. VI lower-bound paragraph and ref. [17]; Crossref record: PRX Quantum 3(4), 040303, online 2022-10-07); fold-in: Dalzell 56 kappa + 1.05 kappa ln(1/eps) bound and Table 1 comparison from a cut entry whose source was read 2026-10-07 (arXiv:2406.12086v2 PDF via WebFetch + pdftotext: abstract "56κ + 1.05κ ln(1/ε) + o(κ)", Sec. 6 Eq. (48), Table 1 rows and caption, "16 × 16 ... up to κ = 50 ... 15κ + 2.1κ ln(1/ε)" and footnote 6, Appendix Theorem 4 Eq. (133); arXiv abstract page: v1 2024-06-17, v2 2026-04-08, no journal ref)
- strength: strong
- counter: (skeptic side) linear-in-kappa is optimal, but kappa itself is polynomial in problem size for PDE discretizations — kappa = O(N^(2/d)) for FEM stiffness matrices with N unknowns in d dimensions (Montanaro and Pallister, PRA 93, 032324 (2016), Sec. The rigorous constant for this method is 234470 kappa + 4 kappa ln(2/eps) block-encoding queries, about 234562 kappa at (kappa, eps) = (10^5, 10^-10) (Dalzell arXiv:2406.12086 Table 1, read 2026-10-07; Dalzell's figure includes a factor of 2 for Hermitianizing non-Hermitian A, per his Table 1 caption).

### QCS-004 — QLSA for FEM gives at most a polynomial speedup in fixed dimension once discretization error is co-refined
- claim: When the number of unknowns N is chosen to meet a target accuracy eps rather than treated as free, the quantum linear-equations algorithm applied to the finite element method is at most polynomially faster than conjugate gradient in fixed spatial dimension d with smooth solutions — roughly quadratic for d = 4 (3+1) — and can be slower in low d.
- numbers: Table I (linear elements, Õ hides polylogs; task = linear functional of the solution to accuracy eps): classical CG Õ((|u|_2/eps)^((d+1)/2)) without preconditioning, Õ((|u|_2/eps)^(d/2)) with optimal preconditioning; quantum Õ(||u|| |u|_2^2/eps^3 + ||u||_1 |u|_2/eps^2) without preconditioning, Õ(||u||_1/eps) with optimal preconditioning (||u|| = L2 norm, |u|_l = Sobolev l-seminorm, ||u||_l = Sobolev l-norm). FEM stiffness matrix: kappa = O(N^(2/d)), sparsity s = O(1). Classical cost scales as eps^(-O(d)); the quantum eps-exponent is d-independent. Barriers (Sec. I.A, proved in Sec. IV.A): any algorithm using the QLE subroutine as a black box to distinguish output states at Euclidean distance eps needs Omega(1/eps) uses, and to distinguish states with overlap 1 - eps (distance O(sqrt(eps))) needs Omega(1/sqrt(eps)) uses; oracle-given inputs allow at most quadratic speedup.
- source: A. Montanaro, S. Pallister, "Quantum algorithms and the finite element method," Phys. Rev. A 93, 032324 (2016), doi:10.1103/PhysRevA.93.032324; arXiv:1512.05903. https://arxiv.org/abs/1512.05903
- verified: 2026-10-07 — arXiv abstract via WebFetch (journal ref and DOI from the arXiv API record); arXiv PDF v2 via WebFetch + pdftotext: Sec. I.A "New results" with Table I, Sec. II (kappa = O(N^(2/d)), CG cost), end of Sec. III (overall quantum runtime). Corroboration: local Qu-FEM PDF /Users/agallojr/proj/src/research-notes/bus/memory/refs/ref-20260809-0032-qu-fem-finite-element.pdf (arXiv:2510.18150), Sec. 1 and Table 1, which adopt the same framing and quote MP's conclusion; independently re-verified 2026-10-07 (arXiv:1512.05903v2 PDF via pdftotext: Table I all four cells, Sec. I.A "approximately quadratic" for d = 4 and "can actually be worse than the classical algorithm", Sec. II kappa = O(N^(2/d)) and s = O(1), Sec. IV.A Omega(1/eps) and Omega(1/sqrt(eps)) black-box bounds, Sec. V two-regime conclusion; Crossref record: PRA 93(3), 032324, online 2016-03-17; local Qu-FEM PDF Sec. 1 quotation of MP and Table 1 caption)
- strength: strong
- counter: MP's own Sec. ### QCS-005 — Heat equation end to end: at most a quadratic quantum speedup, and the QLSA route is never the fastest
- claim: For the heat equation in a d-dimensional rectangle, with the task of estimating the heat in a region to accuracy eps, the best quantum method beats the best classical method by at most a quadratic factor (Õ(eps^-2) to Õ(eps^-1)) for d >= 2, loses to the classical FFT for d = 1, and the quantum-linear-equations approach is never the fastest quantum or classical option.
- numbers: Table I (runtime in eps and d only; Õ hides polylogs; FTCS finite differences): classical linear equations (CG) Õ(eps^-2), Õ(eps^-2.5), Õ(eps^-3), Õ(eps^(-d/2-1.5)) for d = 1, 2, 3, >= 4; classical FFT Õ(eps^(-d/2)); classical fast random walk Õ(eps^-2) all d; quantum linear equations Õ(eps^-2.5), Õ(eps^-2.5), Õ(eps^-2.75), Õ(eps^(-d/4-2)); quantum fast-random-walk amplitude estimation Õ(eps^-1) all d. Ten methods compared (five classical, five quantum); bounds assume no preconditioner.
- source: N. Linden, A. Montanaro, C. Shao, "Quantum vs. classical algorithms for solving the heat equation," Commun. Math. Phys. 395(2), 601–641 (2022), doi:10.1007/s00220-022-04442-6; arXiv:2004.06516. https://arxiv.org/abs/2004.06516
- verified: 2026-10-07 — arXiv abstract via WebFetch; arXiv PDF v2 via WebFetch + pdftotext: Sec. A "Our results," Table I and the bullet conclusions following it; journal reference via the Crossref API record for the DOI; independently re-verified 2026-10-07 (arXiv:2004.06516v2 PDF via pdftotext: Sec. I.A method list of five classical and five quantum algorithms, Table I every cell quoted above, the four bullet conclusions including "For d = 1, the quantum methods are all outperformed by the classical Fast Fourier Transform" and "The quantum linear equation solving method is always outperformed by other quantum methods", the no-preconditioner paragraph; Crossref record: CMP 395(2), 601-641, online 2022-08-24)
- strength: strong
- counter: The same paper is a positive result: for d >= 2 there is a provable quantum speedup, quadratic (Õ(eps^-2) to Õ(eps^-1)) via amplitude estimation on a fast classical random walk, and among space-efficient methods (polylog(1/eps) space, which excludes the classical FFT) the speedup holds in every d (Table I bullets, read 2026-10-07). The ranking also assumes no preconditioning, though LMS add that even a perfect preconditioner would bring the QLSA route only level with their coherent-diagonalisation method and "still not competitive with other methods" (Sec. I.A); Bagherimehrab et al., arXiv:2306.11802, claim a kappa-independent, polylog(N) quantum PDE solver via wavelet preconditioning (abstract read 2026-10-07).
- applies-to: qlsa, cfd, classical-baseline, quadratic-speedup, precision, observables

### QCS-006 — Generic quantum ODE solvers pay exp(delta T) for dissipation and Omega(mu(A)) for non-normality
- claim: Any generic quantum solver for du/dt = A u needs Omega(e^(delta T)) queries when the eigenvalues of A have real-part gap delta > 0 (dissipation) and Omega(mu(A)) queries when A is non-normal, so only dynamics unitarily equivalent to a Schrödinger equation (normal A, equal real parts) escapes the overhead.
- numbers: Prop. 5 (diagonalizable A = V D V^-1, b = 0): no generic solver prepares u(T)/||u(T)|| with o(e^(T·max_{i≠j}|Re lambda_i - Re lambda_j|)) queries to the |u(0)> preparation oracle (T = evolution time in the units in which A is expressed); Prop. 6: none with o(mu(A)) queries, mu(A) = ||A†A - AA†||^(1/2) in spectral norm (mu = 0 iff A normal). Inhomogeneous case with negative logarithmic norm and b ≠ 0: min{Omega(log^alpha(1/eps)), Omega(T^alpha)} queries whenever the underlying linear system needs Omega(log^alpha(1/eps)). All bounds are in the query model; the dissipative bound is tied to BQP ≠ PostBQP = PP.
- source: D. An, J.-P. Liu, D. Wang, Q. Zhao, "Quantum differential equation solvers: limitations and fast-forwarding," Commun. Math. Phys. 406(8), 189 (2025), doi:10.1007/s00220-025-05358-7; arXiv:2211.05246. https://arxiv.org/abs/2211.05246
- verified: 2026-10-07 — arXiv abstract via WebFetch; arXiv PDF v3 via WebFetch + pdftotext: Sec. 1.1.1 "Results," Sec. 3.3.1 Proposition 5 (with proof setup Eqs. 25-33), Sec. 3.3.2 Proposition 6, Table 1; journal reference via the arXiv API record; independently re-verified 2026-10-07 (arXiv:2211.05246v3 PDF via pdftotext: Sec. 1.1.1 real-part-gap and non-normality bounds, PostBQP = PP remark, min{Omega(log^alpha(1/eps)), Omega(T^alpha)} statement and "normal and all the eigenvalues have the same real parts" conclusion via shifting equivalence; Sec. 3.3.1 Proposition 5 verbatim; Sec. 3.3.2 Eq. (44) and Proposition 6 verbatim; Sec. 1.2 and Table 1 fast-forwarding summary; Crossref record: CMP 406(8), art. 189, online 2025-07-02; arXiv page v3 dated 2025-07-09)
- strength: strong

Schrödingerisation (Jin, Liu, Yu, Phys. Rev. Lett. 133, 230602 (2024), arXiv:2212.13969; abstract read 2026-10-07) recasts any linear PDE as a system of Schrödinger equations in real time so Hamiltonian-simulation machinery applies directly.

## B. Input and output: state preparation, QRAM, readout, sampling

### QCS-007 — Active QRAM erases the asymptotic quantum linear-algebra advantage
- claim: Any QRAM needing active control per query (the error-corrected circuit model included) costs Omega(N) control operations or energy per query to N entries, and in the small-scale (shared-memory) regime a parallel classical machine using the same control hardware matches the quantum polynomial eigenvalue transform asymptotically; the authors flag architectural nuance at medium and large scale.
- numbers: Theorem 4.1: Omega(k) QRAM queries for a degree-k polynomial eigenvalue transform f(H)|psi> of a d-sparse N x N Hermitian H; Theorem 4.2: parallel classical computes f(H)v exactly in O(k) matrix-vector products; small-scale regime (P = Theta(dN) processors, classical processors proportional to the Nd QRAM registers): classical O~(k) vs quantum Omega~(k), "no asymptotic quantum advantage at this scale" (Sec. 4.3). Energy: one visible photon per bit per access is about 1 kJ per access at 2^50 bits, 1 GJ at 2^80 bits; general: N-bit access needs Omega(N) energy/computation or O(1/N) per-component error rates (Sec. 3). Aaronson's earlier version of the same point: quantum RAM must be "passive" (no per-element processor) or an O(log^2 n)-step parallel classical solver (Csanky 1976) exists (S. Aaronson, "Read the fine print," Nature Physics 11(4), 291-293 (2015-04), doi:10.1038/nphys3272; footnote 2 of the author's preprint https://www.scottaaronson.com/papers/qml.pdf).
- source: S. Jaques, A. G. Rattew, "QRAM: A Survey and Critique", Quantum 9, 1922 (2025), DOI 10.22331/q-2025-12-02-1922, arXiv:2305.10310v2.
- verified: 2026-10-07 — arXiv abstract via WebFetch; full PDF Sec. 4.3 (Theorems 4.1, 4.2, scale regimes), Sec. 3 energy paragraph, Sec. 11 Discussion via pdftotext on the WebFetch-saved PDF; independently re-verified 2026-10-07 (arXiv abstract 2305.10310v2 via WebFetch; Crossref record for 10.22331/q-2025-12-02-1922; full PDF via pdftotext: abstract active/passive definitions, Sec. 3 energy and Omega(N) paragraphs, Sec. 4.3 Theorems 4.1-4.2 and small-scale regime, Sec. 7.1 surface-code-implies-active passage, Sec. 11 "linear gate cost (regardless of depth)" sentence; energy paragraph corrected from Sec. 6 to Sec. 3; counter 2012.05340 abstract); fold-in: passive-QRAM / Csanky O(log^2 n) point from a cut entry whose source was read 2026-10-07 (Aaronson author-preprint PDF via WebFetch + pdftotext, footnote 2 on passive QRAM and O(log^2 n) classical parallel inversion; Crossref record for doi:10.1038/nphys3272).
- strength: moderate
- counter: Hann, Lee, Girvin, Jiang prove bucket-brigade QRAM query infidelity scales only logarithmically with memory size under arbitrary error channels, so high-fidelity queries are possible without error correction and the advantage persists with it (PRX Quantum 2, 020311 (2021), arXiv:2012.05340, abstract read 2026-10-07). Jaques-Rattew themselves concede circuit QRAM "has a linear gate cost (regardless of depth)" and still helps quantum chemistry and some cryptographic attacks (Sec. 11), and their obstacles "are not provably inevitable" (abstract). Structured PDE stencils need no QRAM at all: for PDE discretizations A is generated algorithmically and b is known from the problem description (Montanaro and Pallister, PRA 93, 032324 (2016), arXiv:1512.05903, Sec. I, read 2026-10-07).
- applies-to: qram, state-prep, qlsa, hhl, qsvt, dequantization, hardware
- stale-after: 2027-10-01

### QCS-008 — Reading out the full N-amplitude solution needs Theta~(N) copies
